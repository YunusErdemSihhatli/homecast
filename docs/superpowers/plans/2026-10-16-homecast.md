# HomeCast Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An ad-free, tracker-free Android app that captures the video playing on any web page in its built-in browser and casts it to a Chromecast-enabled TV (Xiaomi TV Box S) through a local header-injecting proxy, with an in-house Cast (CASTV2) sender, discovery + manual IP connect, subtitles and live streams.

**Architecture:** Single `app` module, packages split by responsibility. Pure-Kotlin cores (HLS rewriter, SRT→VTT, media classifier, Cast frame codec, redirect guard) are JVM-unit-tested. A Ktor CIO proxy and a TLS Cast client run inside a foreground service; Compose UI (Material 3) follows the official architecture guide (ViewModels exposing `StateFlow` UI state, manual DI through an `AppGraph` owned by the `Application`).

**Tech Stack:** Kotlin, Jetpack Compose + Material 3, AndroidX WebKit, Ktor server (CIO), OkHttp, kotlinx.serialization, kotlinx.coroutines, androidx.media (MediaSession), JUnit 4, kotlinx-coroutines-test, Turbine, OkHttp MockWebServer, okhttp-tls (test certificates), Spotless + ktlint, Android Lint, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-16-home-cast-design.md`

## Review Focus

1. **Playlist URL redirects / signed query strings** — upstream playlist served after a 302 to a CDN, with relative segment URIs and `?token=` query strings: relative URIs must resolve against the *final* (post-redirect) URL and keep their query strings. Test in Task 3 (`resolvesAgainstFinalUrlAndKeepsQuery`) and Task 5 (`followsRedirectBeforeRewriting`).
2. **Segments disguised as images** — a `.png` URL whose body is a PNG header followed by MPEG-TS packets: the proxy must strip the prefix, serve `video/mp2t`, and `LOAD` must carry `hlsSegmentFormat: "ts"`. Test in Task 4 (`findsTsSyncAfterPngPrefix`) and Task 5 (`stripsImagePrefixFromSegment`).
3. **TV abandons a request mid-stream** (seeking, stopping) — the upstream OkHttp call must be cancelled and the response body closed; no thread/connection leak after repeated seeks. Test in Task 5 (`clientDisconnectCancelsUpstream`).
4. **Phone not on Wi-Fi / Wi-Fi IP changes** — no Wi-Fi IPv4 means "Play on TV" shows a "Connect your phone to the same Wi-Fi as the TV" error instead of sending a `127.0.0.1`/mobile-data URL; on a network change the proxy rebinds and the next LOAD uses the new IP. Test in Task 10 (`playFailsWithoutWifiAddress`, `rebindsProxyWhenAddressChanges`).
5. **Candidate flood on ad-heavy pages** — dozens of short `.mp4` candidates (ad pre-rolls from non-blocklisted hosts) plus the real HLS master: the list is de-duplicated and the HLS master ranks first. Test in Task 4 (`hlsMasterRanksAboveFilesAndDuplicatesCollapse`).

- Produces:
  ```kotlin
  data class ProxiedSubtitle(val trackId: Int, val url: String, val label: String, val language: String?)
  data class ProxySession(val token: String, val mediaUrl: String, val contentType: String, val isLive: Boolean,
                          val hlsSegmentFormat: SegmentFormat?, val subtitles: List<ProxiedSubtitle>)
  class ProxyServer(private val client: OkHttpClient) {
    val port: Int                                      // 0 until started
    fun start(bindHost: String = "0.0.0.0")            // random free port
    fun stop()
    fun setAdvertisedHost(host: String)                // Wi-Fi IPv4 put into URLs
    suspend fun createSession(candidate: VideoCandidate, subtitles: List<SubtitleSource>): ProxySession   // throws ProxyException
    fun addSubtitle(token: String, source: SubtitleSource): ProxiedSubtitle
    fun closeSession(token: String)
    fun closeAll()
  }
  class ProxyException(val reason: Reason, message: String) : Exception(message) { enum class Reason { UPSTREAM_REJECTED, UPSTREAM_NOT_FOUND, UPSTREAM_UNREACHABLE, NOT_MEDIA, UNSUPPORTED_DASH } }
  object ProxyUrls {
    fun build(host: String, port: Int, token: String, upstream: String, ext: String): String  // http://host:port/s/{token}/u/{base64url(upstream)}.{ext}
    fun parse(path: String): Pair<String /*token*/, String /*upstream*/>?
  }
  ```
- Behaviour fixed by the spec: tokens = 128-bit `SecureRandom`, base64url; unknown token → 404. Every response carries `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Headers: *`, `Access-Control-Expose-Headers: Content-Length, Content-Range`; `OPTIONS` → 204. Upstream request headers: `User-Agent`, `Referer`, `Origin`, `Cookie` from the session, plus the TV's `Range`. Extensions/content types: playlist `.m3u8` → `application/vnd.apple.mpegurl` (never cached, `Cache-Control: no-store`); TS segment `.ts` → `video/mp2t`; fMP4 `.m4s`/init `.mp4` → `video/mp4`; AAC `.aac` → `audio/aac`; key `.key` → `application/octet-stream`; subtitle `.vtt` → `text/vtt; charset=utf-8`; direct file keeps upstream content type (fallback by extension). Upstream status/`Content-Range`/`Content-Length`/`Accept-Ranges` passed through for direct files.
- `createSession`: fetch the candidate URL once (follow redirects). If HLS: record final URL as base; if master, fetch first variant to decide `isLive` and fetch its first segment's first 1 KB (Range `bytes=0-1023`) to set `hlsSegmentFormat`. If FILE: HEAD/Range probe only. DASH → `UNSUPPORTED_DASH`. Status 401/403 → `UPSTREAM_REJECTED`; 404/410 → `UPSTREAM_NOT_FOUND`; IO error/timeout → `UPSTREAM_UNREACHABLE`; HLS body not `#EXTM3U` → `NOT_MEDIA`. Subtitle URL sources are fetched lazily when the TV asks, decoded with `SubtitleDecoder`, converted with `SrtToVtt.ensureVtt`; `inlineVtt` sources served from memory. Track IDs start at 1.
